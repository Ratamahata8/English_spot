# English Spot

Интерактивный английский для ребёнка 8–10 лет с пробелами в базовых знаниях. Первый модуль — **School Again!**, учебные цели Unit 1a Spotlight 3, часть 1, стр. 10. Упражнения, текст объяснений, маскот Спотти и восемь SVG-иллюстраций созданы для приложения. Страницы, диалоги и изображения учебника не распространяются.

## Что работает

- 33 последовательных задания, пять механик: изучение восьми слов, выбор картинки на слух, выбор слова, сборка букв, сборка предложения нажатием. Буквы и слова можно убрать или отменить последний выбор.
- Общий интерактивный текст: кнопка `?`, затем нажатие на слово; длительное нажатие тоже открывает карточку. Английские `school bag` и `pencil case` распознаются как целые словосочетания. Перевод, британская IPA, объяснение, пример, готовое аудио и очередь повторения. Карточка доступна с клавиатуры, закрывается Escape.
- Три уровня помощи: слово, смысл фразы, пошаговая стратегия с похожим примером. Варианты ответов также интерактивны. В повторение можно добавить и предмет, и служебное слово вроде `my`: для них используется выбор значения. Чтобы выбрать ответ после помощи, выключите режим `?` или нажмите вне текста варианта.
- Детерминированная помощь после двух ошибок при сборке предложения: `This is…` или `my / your`. Мини-урок содержит объяснение, аудио и проверяемый вопрос. После него сохраняется исходный собранный ответ. Максимум два автоматических мини-урока за посещение экрана урока, каждый не больше одного раза. Можно сразу вернуться и продолжить позже.
- Словарь с поиском на двух языках, очередь сложных слов, достижения, программа с честно недоступными будущими уроками, две самостоятельные базовые микротемы и примеры вопросов о предмете и имени.
- IndexedDB после каждого ответа/задания; продолжение по стабильному ID после обновления страницы. Перезапуск урока сохраняет статистику слов. Полный сброс требует подтверждения. Экспорт/импорт JSON проверяет версию, ID и числовые поля; импорт подтверждается.
- Кабинет родителя: посещения урока, учебное время (периодическое сохранение каждые 10 секунд и при уходе), ошибки по словам и двум базовым темам, помощь, рекомендации. На экране завершения урока или повторения таймер останавливается; открытие завершённого урока или пустой очереди не добавляет занятие.
- Мобильный интерфейс, большие кнопки, клавиатура, медленное воспроизведение 0.75× с `preservesPitch`, отключение анимаций и `prefers-reduced-motion`.

## Быстрый старт

Нужны Node.js 24, npm, Python 3.12+, `ffmpeg` / `ffprobe` (проверка настоящих MP3). На Debian/Ubuntu: `sudo apt-get install ffmpeg`.

```bash
npm ci
npm run dev
```

Vite по умолчанию использует `/English_spot/`. Откройте адрес, который напечатает Vite, с этим префиксом. Маршруты работают через HashRouter (`/English_spot/#/dictionary`), поэтому перезагрузка на GitHub Pages не требует серверных редиректов.

```bash
npm run typecheck
npm run check:content
npm run check:audio
npm test
npm run build
npm run preview
```

`npm run build` обязательно проверяет TypeScript, целостность контента и MP3. Сеть и генерация речи при сборке не нужны. В репозитории находятся готовые MP3, манифест с голосом и SHA256. Отсутствие, короткий/нечитаемый файл или неверная сумма останавливают проверку.

## Аудио: реальное состояние и воспроизводимость

Создано **40 MP3**: 27 словарных единиц (включая все восемь предметов и служебные слова подсказок), 12 предложений/вопросов и одна конструкция `This is`. Это записанная синтезированная речь, воспроизводимая через HTMLAudioElement; браузерный SpeechSynthesis не используется.

Основной генератор — Python + `edge-tts==7.3.1`, голос **en-GB-SoniaNeural**. В облачной среде на момент реализации прокси запрещал `speech.platform.bing.com` (HTTP 403). В сетевом черновике добавлен этот домен, но открытие доступа нужно применить в настройках среды. Не отключайте TLS и не обходите прокси.

По разрешённому в ТЗ альтернативному пути поставляемые файлы созданы **eSpeak NG, голос `en-gb`**, локально, через WASM и ffmpeg. Это британский формантный голос с заметно роботизированным тембром, **не Sonia и не нейронная запись**. Для хорошего детского произношения рекомендуется заменить его Sonia и прослушать все записи с преподавателем перед регулярными занятиями. Происхождение каждого файла явно указано в `voice` манифеста.

```bash
python3 -m venv .venv
.venv/bin/pip install -r scripts/requirements-audio.txt
# Предпочтительный голос; нужна сеть к speech.platform.bing.com:
.venv/bin/python scripts/generate_audio.py
# Полностью локальная альтернативная генерация после npm ci:
.venv/bin/python scripts/generate_audio.py --engine espeak
python3 scripts/validate_audio.py
```

Генератор извлекает уникальные строки из JSON, использует стабильные имена по SHA256 текста, временный файл и атомарную замену, сохраняет манифест после каждой удачной записи. Повторный запуск продолжает с места ошибки. Смена движка заменяет записи другого голоса; `--force` пересоздаёт все, `--limit N` полезен для диагностики. Файлы не создаются во время работы сайта. Не коммитьте `.venv` и зависимости.

Лицензии и происхождение: [ASSETS.md](ASSETS.md). eSpeak NG — GPL-3.0-or-later, используется только как инструмент сборки; его код и WASM в приложение не включаются. Созданные автором проекта иллюстрации и локальные речевые записи доступны под CC0-1.0. При замене на сторонний голос учитывайте условия соответствующего сервиса.

## Архитектура

- `src/app/` — роутер и оболочка.
- `src/components/` — общие карточки подсказок, интерактивный английский текст, аудиокнопка.
- `src/features/` — экраны, упражнения, дополнительные мини-уроки.
- `src/lessons/school.json` — декларативный контент, варианты, ответы, пояснения, метаданные навыков, грамматика и пять микротем (две активны, три подготовлены).
- `src/types/` — Lesson, VocabularyItem, Exercise, Hint, GrammarRule, RemedialLesson, AudioAsset, LearningProgress.
- `src/services/learning.ts` — чистые функции: проверка ответов, прогресс, освоение, интервалы и выбор микроурока.
- `src/services/storage.ts` — интерфейс `ProgressRepository` и реализация Dexie; схема IndexedDB v1. Импорт имеет отдельную строгую проверку.
- `src/stores/progress.ts` — Zustand и последовательная очередь записи, отображение ошибок сохранения.
- `src/services/audio.ts` — готовые MP3, один активный проигрыватель, скорость, остановка при уходе из урока.
- `scripts/` — генерация и независимая офлайн-проверка аудио/контента.
- `tests/` — Vitest, IndexedDB с fake-indexeddb, Playwright.

Компоненты работают через store и интерфейс хранилища, без прямых обращений к Dexie. Для Cloudflare Workers/D1 нужно реализовать `ProgressRepository` через API, добавить серверную схему, аутентификацию, синхронизацию и обработку конфликтов. UI и чистые учебные функции можно сохранить. Сервер и авторизация сейчас отсутствуют.

### Учебный алгоритм

`INTERVAL_DAYS = [1, 3, 7, 14]` в `services/learning.ts`. Ошибка ставит слово в очередь текущего занятия и сбрасывает серию самостоятельных успехов. Успех назначает дату следующего повторения. Подсказка учитывается отдельно и не повышает уровень освоения. После правильного ответа без помощи слово уходит из явной очереди; автоматически вернётся по сроку. Слово считается освоенным после минимум трёх самостоятельных успехов и серии из трёх, а не после одного ответа. Уровень — 0–4. Задания знакомства не засчитываются как проверка знания.

Счётчики посещений описывают входы в урок/повторение; это не календарные дни и не доказательство активного внимания ребёнка. Доля помощи — обращения к помощи / (обращения + ответы). Данные остаются на устройстве, очистка браузерных данных удалит их; делайте экспорт.

## Тестирование

```bash
npm test
# В среде уже есть /usr/bin/chromium:
npm run test:e2e
# На другой машине:
npx playwright install --with-deps chromium
CHROMIUM_PATH="$(node -e "console.log(require('@playwright/test').chromium.executablePath())")" npm run test:e2e
```

Playwright запускает Vite самостоятельно. Для проверки готовой сборки выполните `npm run build`, затем `E2E_PRODUCTION=1 npm run test:e2e`; этот режим используется в CI. E2E проходит все 33 задания с намеренной ошибкой, карточкой подсказки, аудиозапросом, двумя ошибками в предложении и мини-уроком; проверяет возврат, сохранение после перезагрузки, повторение, мобильную ширину 390px, поиск, настройки, экспорт/импорт, клавиатуру и долгое нажатие. Скриншоты и отчёт — в игнорируемых `test-results/` и `playwright-report/`.

На момент реализации проходят 13 unit-тестов и 7 E2E-сценариев. Vitest проверяет ответы и порядок слов, стабильные ID, завершение, интервалы, ошибки/подсказки, ограничения адаптации, импорт, восстановление IndexedDB и полноту манифеста с SHA256. Дополнительная Python-проверка использует ffprobe и полное декодирование FFmpeg для всех 40 MP3.

## GitHub Pages

Workflow `.github/workflows/pages.yml` при push в `main` выполняет npm ci, TypeScript, контент, аудио, Vitest, Playwright и production build, затем загружает артефакт и публикует Pages. Pull request проходит проверки без публикации. Генерация речи в CI не запускается.

1. Отправьте подготовленные изменения в `main`.
2. В GitHub → Settings → Pages выберите **GitHub Actions** как источник.
3. Дождитесь успешного workflow; реальный адрес появится в шаге deploy.

Для этого репозитория ожидаемый путь — `/English_spot/`. Workflow вычисляет имя репозитория автоматически; локально другой путь задаётся `VITE_BASE_PATH=/other/ npm run build`. Для корня собственного домена — `VITE_BASE_PATH=/`. Ссылки на иллюстрации и MP3 используют `import.meta.env.BASE_URL`.

Наличие workflow не означает, что сайт уже опубликован. Публикация начнётся после слияния изменений в `main` и настройки Pages. Сайт пока не опубликован.

Второй урок не требует новых компонентов, если использует существующие пять механик. Новые учебные механики добавляются отдельной веткой рендера и типом Exercise.

## Ограничения MVP

Один ученик и один рабочий основной урок; нет облачной синхронизации, авторизации, микрофонной оценки произношения, фонового офлайн-кэша или уведомлений. Три будущие микротемы и будущие уроки явно помечены недоступными. Данные локальные, импорт поддерживает только схему 1 и первый урок. Это самостоятельный тренажёр по учебным целям, а не цифровая копия или официальное издание Spotlight. Озвучка поставляется альтернативным британским синтезатором; Sonia требует разрешённого сетевого доступа и повторной генерации.
