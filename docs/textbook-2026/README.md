# Учебник Spotlight 3: часть 1, 16-е издание, 2026

Этот источник имеет ID `spotlight_textbook_2026_16_part1`. Он **не равен** сборнику `spotlight_workbook_2026_17`. Страницы и достижения сборника не подтверждают изучение новой страницы учебника.

## Состояние источника

Папка фотографий: https://drive.google.com/drive/folders/1gV7Jqhbvlj2E-V7ypjtSffEp_gmUav0i

Попытки получения папки блокируются прокси среды: `403 CONNECT tunnel failed` при соединении с `drive.google.com`. Ответ возникает до соединения с Google Drive, поэтому он не доказывает, что права самой папки неверны. Изменённые пользователем права папки пока технически проверить невозможно. Сохранён черновик разрешений для `drive.google.com` и `drive.usercontent.google.com`; он требует публикации в настройках среды. Уже разрешённые GitHub и сервис озвучки сохранены.

Фотографии не перечислены и не скачаны. Число файлов, реальных печатных страниц и слов источника **неизвестно**, а не равно нулю. Новые страницы не объявлены готовыми. Старый PDF, комиксы, авторские уроки и сборник не использованы вместо фотографий.

## Независимый аудит существующего проекта

Выполнить из корня:

```sh
node --import tsx scripts/audit_textbook.ts
```

Команда создаёт три отчёта:

- `textbook-coverage.json`: доступ к запрошенному источнику, неизвестные общие числа и отсутствие готовых страниц нового издания.
- `vocabulary-coverage.json`: отдельно неизвестное покрытие нового учебника и реальные индексы существующего приложения; отсутствующие атомарные словоформы со ссылками на текущие авторские задания.
- `audio-coverage.json`: отдельно неизвестный корпус нового источника и наличие/SHA256 существующих MP3. Этот аудит не заменяет FFmpeg и браузерное воспроизведение.

Текущие индексы:

| Индекс | Записей |
|---|---:|
| Слова, видимые в словаре «Моих уроков» | 110 |
| Слова и выражения глобальных подсказок «Моих уроков» | 162 |
| Словарь сборника 2017 | 173 |
| Словарь сборника 2026 | 407 |
| Уникальные формы/выражения при объединении существующих индексов | 479 |

`who`, `when`, `why` отсутствуют во всех четырёх индексах. `what`, `where`, `how` есть в словарях сборника, но отсутствуют в индексе глобальных подсказок прежних уроков. `is`, `are`, `have`, `do`, `does` есть в прежних подсказках, но не видны как самостоятельные карточки в словаре «Моих уроков», поскольку он строится по тематическим словам, а не по всему лексикону. Обнаруженные ошибки здесь ещё не исправляются путём приписывания слов новому учебнику без фотографий.

Аудит атомарных словоформ отличается от подсказки к словосочетанию: `school bag` может иметь общую карточку при отсутствии самостоятельной карточки `bag`. Неправильные варианты выбора не становятся допустимыми словоформами. Буквенные заготовки и заполнители сеток не считаются лексикой. Проценты этих диагностических сравнений **не являются покрытием фотографий учебника**.

В прежнем читателе комиксов есть перевод и объяснения реплик, но не подключены глобальные токены `EnglishText` для каждого слова. Сами эти страницы не имеют подтверждённой привязки к фотографируемому изданию 16/2026.

В существующих четырёх аудиоманифестах — 2483 записи. Проверены наличие файлов и SHA256; отсутствующих или изменённых файлов не найдено. Для нового учебника аудиокорпус пока неизвестен, новых записей не создано.

## Следующие этапы после доступа к фотографиям

1. Перечислить и скачать все изображения вне публичного Git; проверить пагинацию/повторы/качество и визуально прочитать страницы, разделяя развороты. Сохранить доказательства употреблений и отдельно нечитаемые участки.
2. Выделить реальную лексику и словоформы из фотографий; связать с нормализованными лексемами/значениями/произношениями. Слова собственных объяснений хранить отдельно. Проверить все реальные формы и служебные слова, включая `who`.
3. Сгенерировать и проверить британские MP3 для слов, форм и собственных обучающих предложений.
4. Создать действительные уроки страниц с объяснениями, подготовкой, адаптацией ошибок, повтором и обратным переходом из сборника; сопоставлять реальные темы, а не номера модулей.
5. Добавить отдельные идентификаторы источника и миграции без удаления существующих таблиц IndexedDB; не приписывать прежние результаты новым страницам.
6. Проверить полноту относительно всех доступных фотографий и слов, упражнения, мобильный интерфейс, MP3, сохранения, Pages и полный production E2E.

Основная реализация по фотографиям остаётся заблокированной. Этот этап — проверяемый аудит и отчёты, а не реализация уроков или объявление полного словаря.
