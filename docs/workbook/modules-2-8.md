## Что именно адаптировано

Каждое найденное исходное упражнение связано с отдельным ID приложения, своей страницей, номером и уроком. Авторские примеры проверяют его учебную цель. Это **не копия всех подпунктов печатного задания**: количество подпунктов оригинала не приравнивается к числу шагов тренажёра. Для чтения написаны собственные короткие тексты; они видны рядом с вопросами. Для таблиц даны собственные исходные факты. Личные ответы собираются конструктором, допускают разные варианты и учитываются как работа с опорой.

Страницы на границах разделов могут относиться к двум модулям: например, на стр. 57 заканчивается №18 модуля 3 и начинается №1 модуля 4. Поиск по странице и номеру сохраняет обе связи. Последняя записанная страница с хорошо различимым номером — 143; номер 144 у последнего разворота восстановлен по продолжению №12 и следующему листу, а не подтверждён читаемым колонтитулом. Это отдельно отмечено в каталоге.

## Источник и ограничения

`docs/workbook/edition-2026-rest-objectives.json` — ручной указатель целей с временными метками и SHA256 кадров. Исходные видео, кадры и OCR остаются вне Git. `src/workbook/data/edition-2026-rest-catalog.json` разделяет нахождение, проверку цели, полноту чтения исходного текста и готовность тренажёра. Полная вычитка всего исходного текста **не заявляется**: часть строк закрыта рукой или снята в движении. Нечитаемые строки не восстанавливались по изданию 2017.

Словарь издания расширен с 314 до 407 подтверждённых форм и выражений. 401 имеют визуальные подтверждения, 6 сохранены из прежнего пользовательского отчёта. Вхождения 2017 не выдаются за 2026; старые ID сохраняются. Производные ответы грамматических упражнений не становятся автоматически «найденными в сборнике» словами. Полнота словаря всей книги пока не достигнута.

## Повторение и сохранения

Каждую тренировку можно повторять после завершения. Прогресс хранится локально в IndexedDB браузера, отдельно по изданиям; это не только HTTP-кеш. Экспорт и импорт доступны в родительском кабинете. Новые ID не сбрасывают предыдущие результаты. Синхронизации между устройствами и серверного аккаунта нет.

## Проверка

`npm run check:rest` проверяет все 204 связи с источником, активные правила, допустимость вариантов, сборку фраз, личные ответы, три подсказки и наличие статических MP3. Браузерные сценарии проходят каждый новый тренажёр до конца, перезагружают страницу и запускают повторное прохождение; для каждого модуля отдельно проверяются мобильный поиск, подготовка и аудио с базовым путём GitHub Pages.

`python3 scripts/build_workbook_rest.py` воспроизводит авторские данные из небольших тематических банков и ручного указателя целей. После регенерации следует пересобрать корпус MP3 и повторить проверки. Подготовка MP3 возобновляется с проверенных файлов и выполняет до четырёх независимых запросов одновременно; обычное приложение использует только локальные статические записи Sonia Neural.
