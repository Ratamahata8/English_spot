# Сборник Spotlight 3: первый этап

Источник: Н. Быкова, М. Поспелова, сборник упражнений, 3 класс, 2017, предоставленный пользователем PDF. В нём 129 PDF-страниц; печатная страница = PDF-страница − 1. SHA256 файла и результаты постраничной проверки — в `source-audit.json`. PDF, сканы, полные тексты упражнений и сырой OCR в этот PR не включены. Новые задания — самостоятельные аналоги учебных целей, а не цифровая копия сборника. Прежний раздел «Учебник» остаётся отдельным.

## Что готово

- Визуально проверен указатель всех 313 упражнений: входной тест, повторение, модули 1–8. `content-coverage.json` содержит номера, страницы, продолжения, тип, навыки, зависимости и честный статус адаптации.
- Полностью адаптированы 33 упражнения модуля 1, печатные страницы 13–24: 110 интерактивных шагов. Каждый источник пройден браузерным тестом. Собственные сетки и примеры; альтернативные грамматически правильные ответы принимаются.
- 17 используемых механик: сопоставление, пропущенные буквы, анаграммы, алфавит, множественное число, грамматика, порядок слов, исправление, лишнее слово, пропуски, перевод, кроссворд, поиск слов, диалог, таблица, шаблон, письмо. Реестр предусматривает также чтение для следующих этапов. Универсальный renderer использует семь типов элементов управления.
- «Подготовиться» перед каждым новым и прежним заданием: слова, звук, простое правило, пример, шаги, два тренировочных вопроса и возврат к исходному вопросу. Граф из 36 навыков, 18 готовых объяснений с 36 вопросами; остальные навыки обозначены как планируемые.
- При повторных ошибках предлагается соответствующая подготовка. Статистика слов, грамматики, смысла, помощи и попыток разделена. Подсказанный ответ и заполнение готового шаблона не дают самостоятельного освоения; грамматический ответ не засчитывает все слова задания.
- Словарь сборника: 173 подтверждённые формы, 144 лексемы, включая 19 многословных форм. UK IPA, контекстные значения, формы и сокращения, самостоятельные примеры, ссылки на источник, фильтры и повторение. Ненаблюдавшаяся нормальная форма явно отделена от подтверждённых форм.
- 476 статических MP3 Sonia Neural для слов, примеров, правил и заданий; 100 файлов повторно используют прежние проверенные записи по SHA256, 376 синтезированы заново. Всего в проекте 928 MP3. Замедление, текущая запись и остановка при переходе работают без сетевого TTS во время занятия.
- Повторный проход, продолжение, родительская статистика и резервные копии. Прежние 17 уроков, 510 упражнений и 55 интерактивных реплик сохранены.

## Что ещё не готово

**Это не полное покрытие сборника.** Осталось 280 интерактивных адаптаций. Для будущих модулей указатель проверен по номерам и типам, но подробная лексическая привязка (`requiredWordIds`) ещё не выполнена; пустой список у `not_started` не означает отсутствие слов. Словарь из 173 форм — опубликованная проверенная часть, не полный словарь книги и не заявление о 100% лексическом покрытии даже модуля 1.

`lexical-candidates.json` содержит 944 OCR-написания для дальнейшей проверки. Это не 944 слова: среди них анаграммы, ошибки распознавания и другие кандидаты. 129 написаний совпадают с опубликованными подтверждёнными формами; остальные 815 требуют разбора. Счётчик совпадений не является процентом покрытия. Порядок токенов, координаты и полные распознанные тексты не публикуются. Полная ручная сверка лексики всех страниц, включая подписи и служебные слова, остаётся отдельной задачей; `lexicalCoveragePercent` в отчёте равен `null`.

Следующие PR: модули 2–8 по очереди, затем оставшиеся повторение/входной тест; словарь дополняется только после проверки конкретных форм и источников. Публикуемые формы всегда должны иметь источник, произношение и IPA; новые парадигмы автоматически не создаются.

## Устройство данных и сохранение

`src/workbook/data/module-one.json` — декларативные авторские задания, `skills.json` — DAG и подготовка. `lexicon.json` — удобное представление форм; `entities.json` содержит связанные лексемы, произношения, значения, вхождения и примеры. `scripts/build_workbook_entities.py` перестраивает связи из проверенных данных, не придумывая слова.

`learning.ts` проверяет ответы и доказательства освоения; `TaskRenderer.tsx` отображает механики; подготовка, словарь и кабинет используют общие компоненты. Реальный текст ошибки определяет рекомендации, но диагноз остаётся педагогической эвристикой, не точным определением причины ошибки.

Dexie обновлён до версии 4 добавлением таблицы `workbook`; старые таблицы не удаляются. Прогресс остаётся в IndexedDB этого браузера, без аккаунта и облачной синхронизации. При отказе IndexedDB результат удерживается в памяти, переход на экран успешного завершения блокируется; доступна кнопка повторного сохранения. Смена раздела не перезаписывает несохранённое состояние старыми данными. Полная перезагрузка вкладки при продолжающемся отказе хранилища остаётся небезопасной, об этом показывает сообщение.

Экспорт версии 2 содержит необязательное поле `workbook`; импорт старого экспорта без этого поля сохраняет существующий прогресс сборника. Перед экспортом ожидаются записи; перед сбросом/импортом завершается очередь, чтобы запоздавшая запись не восстановила удалённое состояние. Статистика времени считается только в активном задании и подготовке, не на экране результата. Схема сохранения сборника — версия 1.

## Озвучка и права

```bash
# Только подготовка, не требуется для сборки или браузера
.venv/bin/python scripts/workbook_audio.py --corpus
.venv/bin/python scripts/workbook_audio.py --generate
# Проверка имеющихся файлов, без синтеза и сети
python3 scripts/workbook_audio.py
```

Конфигурация — `audio-provider.json`. Британский голос `en-GB-SoniaNeural` выбран для совместимости с ранее одобренной озвучкой; записи синтетические, не голос разработчика или аудиоприложение издательства. Генерация требует доступа к `speech.platform.bing.com`; приложение загружает только собственные MP3. Проверяются текст, голос, SHA256, ffprobe и полное декодирование FFmpeg.

**Коммерческие права на голос не подтверждены:** лицензия LGPL библиотеки edge-tts не предоставляет лицензию на голос сервиса Microsoft. Настройка `commercialRights: not-verified` намеренно сохранена. Для перехода на записи с подтверждёнными правами поддержан `--provider import --import-dir /path/to/mp3`: файлы с именами по хешу текста, та же проверка и тот же runtime. Условия провайдера/полученные права нужно проверить отдельно; приложение не обещает разрешения на коммерческое использование.

## Проверка и публикация

```bash
npm ci
npm run format:check
npm test
npm run build
E2E_PRODUCTION=1 npm run test:e2e
```

Для build нужны Python 3, ffmpeg/ffprobe; для E2E — Chromium (по умолчанию `/usr/bin/chromium`, можно задать `CHROMIUM_PATH`). Контроль данных и всех аудио включён в production build, следовательно выполняется и прежним GitHub Actions workflow. `VITE_BASE_PATH` по умолчанию `/English_spot/`; hash-маршруты, SVG и MP3 проверяются с этим префиксом. Workflow публикует только после push в `main`; этот PR самостоятельно не сливается. Настройки Pages: Settings → Pages → Source: GitHub Actions.
