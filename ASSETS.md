# Происхождение материалов

- `public/illustrations/*.svg`: 111 оригинальных векторных рисунков (110 слов и маскот), созданных для English Spot из геометрических элементов. CC0-1.0; разрешены копирование и изменение без обязательной атрибуции. Иллюстрации не взяты из учебника.
- `public/audio/en-GB/*.mp3`: 290 записей британского голоса **en-GB-SoniaNeural**, созданных через Microsoft Edge TTS инструментом `edge-tts`. Текст, голос и SHA256 каждой записи указаны в манифесте. Это не голос автора проекта и не оригинальные записи издательства. Условия использования голоса определяются соответствующим сервисом; CC0 иллюстраций не распространяется на голосовой сервис.
- `edge-tts==7.3.1`: https://github.com/rany2/edge-tts, LGPL-3.0; используется только для подготовки MP3, не включается в браузерную сборку. Для синтеза не нужны пользовательские API-ключи.
- Ранний MVP использовал eSpeak NG `en-gb`. Все эти записи заменены Sonia. Локальный инструмент `espeak-ng@1.0.2` (https://github.com/ianmarmour/espeak-ng.js, GPL-3.0-or-later) сохранён как необязательная альтернатива генерации. Его код и WASM не включаются в `dist`.
- Учебные упражнения, примеры и объяснения — самостоятельные авторские адаптации целей первой части Spotlight 3. Приложенный PDF использован для сверки тем; его страницы, диалоги, персонажи и изображения не включены в репозиторий.
- Системные шрифты; внешние шрифты, рекламные и аналитические скрипты не загружаются.
