# Происхождение материалов

- `public/illustrations/*.svg`: оригинальные векторные рисунки, созданные для English Spot. CC0-1.0, разрешены копирование, изменение и коммерческое использование без обязательной атрибуции.
- `public/audio/en-GB/*.mp3`: синтезированы из авторских учебных слов и фраз локальным eSpeak NG, вариант `en-gb`, через `scripts/generate_audio.py --engine espeak`; экспорт в MP3 через FFmpeg/libmp3lame. Для этих исходных записей проекта — CC0-1.0. Это не записи из учебника и не голос Sonia. Точный голос и SHA256 — в манифесте.
- Инструмент `espeak-ng@1.0.2`: https://github.com/ianmarmour/espeak-ng.js, GPL-3.0-or-later; исходный eSpeak NG: https://github.com/espeak-ng/espeak-ng. Используется только на этапе генерации, не включается в `dist`.
- `edge-tts`: https://github.com/rany2/edge-tts, LGPL-3.0; альтернативный сетевой инструмент, не включается в `dist`. При генерации через сервис Microsoft соблюдайте условия сервиса; происхождение в манифесте изменится.
- Системные шрифты; внешние шрифты и аналитика не загружаются.
- Приложенный пользователем PDF использован только для сверки учебных целей. Сам PDF, его страницы, персонажи, иллюстрации и оригинальные диалоги не включены в репозиторий.

CC0 1.0: https://creativecommons.org/publicdomain/zero/1.0/
